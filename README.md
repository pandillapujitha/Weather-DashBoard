# 🌤️ Weather Dashboard

A clean and responsive **Weather Dashboard** built using **HTML, CSS, and JavaScript**. The application allows users to search for a city and view its current weather information through a simple and user-friendly interface.

## 🔗 Live Demo

**Live Website:**
https://pandillapujitha.github.io/Weather-DashBoard/

## 📌 Project Overview

The Weather Dashboard is a web-based application designed to provide weather information in an easy-to-understand format.

Users can enter a city name and view relevant weather details through a responsive and visually appealing interface.

## ✨ Features

* 🌍 Search weather by city
* 🌡️ Display temperature information
* ☁️ Show weather conditions
* 💧 Display humidity information
* 💨 Display wind information
* 📱 Responsive design
* 🎨 Clean and modern user interface
* ⚡ Fast and lightweight
* 🌐 Works directly in a web browser

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and dynamic weather data
* **Weather API** – Fetching weather information
* **Git & GitHub** – Version control and project hosting
* **GitHub Pages** – Deployment

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/pandillapujitha/Weather-DashBoard.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd Weather-DashBoard
```

### 3. Run the Application

Open `index.html` in any modern web browser.

No additional installation or server setup is required.

## 🌐 Deployment

This project is deployed using **GitHub Pages**.

Every update can be pushed to the GitHub repository using:

```bash
git add .
git commit -m "Update Weather Dashboard"
git push
```
